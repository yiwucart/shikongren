进入内容管理后台 返回站点
本站用的是 github backend + 自建 OAuth 代理（服务器上 /root/decap-oauth， systemd 服务 decap-oauth）。没有用 git-gateway —— 那个依赖 Netlify，脱离 Netlify 跑不起来。

使用步骤

  1. 点上面「进入内容管理后台」，页面加载后左侧会出现一个 「用 GitHub 登录」按钮（英文是 Log in with GitHub）
  2. 点它 —— 会弹出一个新窗口，跳转到 GitHub 授权页，在新窗口里点「授权」
  3. 授权后会自动跳回后台，左侧就是「文章」列表，可以新建、编辑、删除
  4. 写完点右上角 「保存 / 发布」，内容就进仓库了；服务器 3 分钟内自动重建上线
首次登录时 GitHub 会申请 repo 权限（用于提交文章和上传图片），点授权即可。
如果新窗口没自动关闭，手动关掉它，回到后台页面刷新一下就行。

「发布」之后多久能看到？

服务器每 3 分钟自动检查一次仓库，有新提交就重建全站。所以：

操作生效时间
改文章正文 / 标题 / 栏目点发布后 1～4 分钟
新建文章同上
删除文章同上（会同时从首页和搜索里移除）
上传图片同上
急的话，在后台点发布后等一会儿刷新首页即可；超过 5 分钟没变化就告诉我。

各字段怎么填

字段说明
标题文章标题，必填
发布日期选个日期。首页排序是时间靠后靠前，2026 的排在 2025 前面
栏目从下拉里选。已有 14 个栏目：预测案例、预测理论、风水实务、八字命理、易学基础、化解调理、命运格局、面相手相、择日用事、姓名测字、行业辨伪、学员心得、培训招生、综合论述
标签逗号分隔，可留空。用于站内标签检索
作者默认「吕文艺」，一般不用改
原文链接微信公众号原文地址。转载的文章建议填上
正文支持 Markdown。图片用「媒体库」按钮插入
系列标记例如「九、290局-八」，留空表示不属于系列

插入图片

在正文编辑器里点工具栏的「媒体库 / Media Library」图标，选择本地图片上传即可。上传后会自动生成链接，直接插入正文。

已有的 1069 张历史配图没有全部放进媒体库（体积太大），需要用旧图的话，把图片发给我，我帮你加进去。

不想用后台？把文章发给我

最省事的方式。你把 Markdown 文件发我，我跑脚本重建全站，约 1 分钟。

E:\BaiduNetdiskWorkspace\3yiwucart\AutoBat\08_longxia\workbuddy\吕氏时空人网站\_input\时空坐标\md\

文件名格式：时空坐标_2026-10-20_文章标题.md
文件首行写成：# [标题](原文链接)

或者你从公众号后台拿到的 md 直接丢进来也行，脚本会自动识别。

直接改服务器上的文件

如果你熟悉命令行，可以直接改仓库里的 markdown，然后重建：

/www/wwwroot/shikongren.com/repo/content/posts/

改完执行 /root/deploy.sh 即可重建并上线（定时器也会自动做）。
