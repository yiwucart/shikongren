方式一：在线后台（Decap CMS）

浏览器里写文章、传图片，点发布就上线。已完成技术配置，只差填入 GitHub 凭证。

本站用的是 github backend + 自建 OAuth 代理（服务器上 /root/decap-oauth， systemd 服务 decap-oauth）。没有用 git-gateway —— 那个依赖 Netlify，脱离 Netlify 跑不起来。
进入内容管理后台 返回站点

首次配置（只需做一次）

  1. 建一个 GitHub 仓库（叫 shikongren 即可），把站点内容推进去，分支用 main
  2. 到 https://github.com/settings/applications/new 建 OAuth 应用：
Application name: shikongren.com CMS Homepage URL: https://shikongren.com Authorization callback URL: https://shikongren.com/decap/callback
  1. 拿到 Client ID 和 Client Secret，填入服务器的 /root/decap-oauth/.env：
GITHUB_CLIENT_ID=你的ClientID GITHUB_CLIENT_SECRET=你的ClientSecret GITHUB_REPOSITORY=你的用户名/shikongren
  1. 同时把 admin/config.yml 里的 repo: 改成你的 用户名/shikongren
  2. 访问 https://shikongren.com/admin/，点「用 GitHub 登录」即可进入

说明：仓库需设为 public 或确保你的 GitHub 账号对私有仓库有写权限； 授权时 GitHub 会申请 repo 权限（用于提交文章和上传图片）。
