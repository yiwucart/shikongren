怎么插图

后台正文编辑器插图的完整步骤 · 时空人公益推广

1上传图片

编辑文章时，把鼠标移到正文输入框上，工具栏会出现一排按钮，点其中的图片图标（一个 mountains+sun 的小图）。

  1. 弹出的窗口里有「选择文件」按钮（英文是 Choose an Image 或 Select Media）
  2. 从电脑里选一张图，选完先点「选择 / Select」确认
  3. 图片出现在媒体库列表里，点它的缩略图选中
  4. 下方「Insert / 插入」按钮变亮，点它
  5. 图片就被插进正文了，同时图片文件已经进了仓库的 img/uploads/
如果正文框上方没有图片按钮，可以直接去左侧「Media / 媒体」面板上传 —— 效果完全一样，上传后在那边能看到所有已传图片，随时复用。

2上传时能做的设置

设置项作用建议
文件名 / Alt 文本显示在图下方，也是搜索引擎读图的依据写中文说明，如「足弓示意图」
文件大小上限超过 8MB 会被拒绝手机照片先压到 2MB 以内
格式只接受 jpg / png / gif / webp / svg不要上传 bmp、tiff、heic

已限制 5 种常用格式 + 8MB 上限，防止误把大文件传进仓库拖慢网站。

3调整图片显示尺寸

插图后想控制宽度，直接在正文里把这段文字里的 800 换成你想要的像素数：

![足弓示意图](/img/uploads/足弓示意图2.jpg =800x)

其中 800 就是显示宽度（像素）。手机拍的竖图建议用 600，横图用 800。

4发图前的几条经验

  • 先传图，再保存文章。图片是独立提交到仓库的，如果图还没传完就点发布，文章里的图会显示成裂图。
  • 一张图一次只传一张。批量选择时 GitHub 会限流，容易只成功一半。
  • 文件名用中文或英文都行，但别用空格和特殊符号（# ? & %），会导致链接失效。
  • 不要从微信里直接复制粘贴图片。微信的图有防盗链，粘过来过几天就会裂。必须先下载到电脑再上传。
  • 图片容量大的话，网站打开会变慢。单篇文章插 5～10 张比较合适。
